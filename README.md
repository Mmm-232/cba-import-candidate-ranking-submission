A ranking tool for generating the candidate list of CBA foreign players, accompanied by a locally-run interactive panel of Streamlit.
Its purpose is scouting decision support: helping people narrow down the vast amount of overseas player data into a short list worth further examination, rather than making a blanket statement that someone will definitely be signed. The final judgment still belongs to humans.
```powershell
python -m pip install -r requirements.txt
python -m streamlit run app.py
```
